# 🍔 FoodZone

A modern and interactive Food Browsing Web Application built using **React.js**, **Vite**, **Styled Components**, and **Express.js**. This project allows users to browse food items, search for food, and filter food based on categories like Breakfast, Lunch, and Dinner.

- 🖼️ Display food images
- ⚡ Fast and interactive UI

- 🎨 Styled Components for styling
- 🔗 React frontend connected with Express backend

⚙️ Installation

Clone the repository
git clone https://github.com/Shreeshant-15/React_projects.git
Go to the project folder
cd React_projects/project-4

💻 Frontend Setup

Go to the app folder
cd app
Install dependencies
npm install
Run the development server
npm run dev

The frontend will run on a local URL such as:

http://localhost:5173/

🖥️ Backend Setup

Open another terminal.

Go to the server folder
cd React_projects/project-4/server
Install dependencies
npm install
Start the server
npm start

The backend server will run on:

http://localhost:9000

🔎 How It Works

The application fetches food data from the Express.js backend and displays it in the React frontend.

Users can:

View all available food items.
Search for a specific food item.
Select a category.
Filter food based on:
Breakfast
Lunch
Dinner
View the filtered food results.
