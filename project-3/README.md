# 🎲 Dice Game

A modern and interactive Dice Game built using **React.js** and **Vite**. This project demonstrates React state management, component-based architecture, event handling, conditional rendering, reusable components, and responsive UI design.

## 🚀 Live Demo

🔗 https://mydicegamereact.netlify.app/

## ✨ Features

- 🎲 Interactive dice rolling
- 🎯 Select a number before rolling
- 📈 Dynamic score calculation
- 🔄 Reset score functionality
- 📖 Show/Hide game rules
- ⚡ Fast performance with Vite
- 📱 Responsive UI
- 🎨 Styled Components for styling

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Shreeshant-15/React_projects.git
```

### Go to the project folder

```bash
cd React_projects/project-4
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
